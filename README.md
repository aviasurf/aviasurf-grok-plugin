# Aviasurf for Grok

Official Aviasurf plugin for Grok Build.

Aviasurf helps users search and compare indicative flight prices, explore price calendars, compare airports, discover destinations, inspect route information, and continue to live flight search.

## MCP server

The plugin connects to the official Aviasurf remote MCP server:

https://mcp.aviasurf.com/mcp

No authentication is required.

## Example prompts

- Find indicative flight prices from London to Paris for a one-week round trip next month.
- Show me the cheapest observed dates from New York to Rome over the next six months.
- Compare the indicative prices for the airports serving London and Paris.
- Find direct economy flights with baggage from London to Barcelona next month.
- Show me affordable island destinations from London next month.

## Important

Aviasurf provides cached indicative fare observations. Prices are not guaranteed live availability.

Aviasurf does not book flights, issue tickets, charge payment cards, cancel bookings, or process refunds.
